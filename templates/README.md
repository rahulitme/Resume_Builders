# Resume Templates

Place your 5 resume template PDFs in this folder.

## How to Add Templates

1. **Prepare your templates:**
   - Template 1: `template_1.pdf`
   - Template 2: `template_2.pdf`
   - Template 3: `template_3.pdf`
   - Template 4: `template_4.pdf`
   - Template 5: `template_5.pdf`

2. **Two methods to add:**

   **Method A: Upload through UI (Easiest)**
   - Open the Streamlit app: `streamlit run app.py`
   - Go to the "📋 Templates" tab
   - Scroll down to "📤 Upload Templates (Admin)"
   - Select all 5 template PDFs
   - Click "💾 Save Templates"
   - Templates will be available for download immediately!

   **Method B: Direct File Copy**
   - Copy your template PDFs to this folder
   - Rename them as: `template_1.pdf`, `template_2.pdf`, etc.
   - Refresh the Streamlit app
   - Templates will be available in the Templates tab

## Template Naming Convention

- **template_1.pdf** - First template
- **template_2.pdf** - Second template
- **template_3.pdf** - Third template
- **template_4.pdf** - Fourth template
- **template_5.pdf** - Fifth template

## Features

✅ Users can download templates from the UI  
✅ Templates serve as base resumes  
✅ Templates can be edited and customized  
✅ Edited versions are saved separately  

## Example Workflow

1. User goes to "📋 Templates" tab
2. Sees all 5 available templates
3. Downloads their preferred template (e.g., `template_1.pdf`)
4. Uploads it in the "📤 Upload" tab
5. Configures custom edits in "⚙️ Configure Edits"
6. Processes and downloads personalized resume
